================================================================================
API ENDPOINTS (Summary)
================================================================================

POST /conversations/start
  - Create new conversation
  - Input: patient_id_hash, doctor_id

POST /turns/add
  - Add turn with auto context extraction
  - Input: conversation_id, user_input, ai_response

GET /turns/{conversation_id}
  - Get all turns in a conversation

GET /context/{turn_id}
  - Get enriched context with previous findings

GET /findings/{conversation_id}
  - Get all extracted findings

GET /audit/{turn_id}
  - Get immutable audit log

GET /audit/conversation/{conversation_id}
  - Get full conversation audit trail

GET /context-chains/{conversation_id}
  - Get chains of related findings

================================================================================
EXAMPLE API CALL (curl)
================================================================================

# Start conversation
curl -X POST http://localhost:8000/conversations/start \
  -H "Content-Type: application/json" \
  -d '{
    "patient_id_hash": "patient_123",
    "doctor_id": "dr_001"
  }'

# Add turn with findings
curl -X POST http://localhost:8000/turns/add \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_id": "YOUR_CONV_ID",
    "user_input": "Patient has headache and fever",
    "ai_response": "{\"diagnosis\": \"Migraine\", \"drugs\": [\"Paracetamol\"]}"
  }'

================================================================================
TROUBLESHOOTING
================================================================================

Port 8000 in use?
  docker-compose down
  lsof -i :8000 && kill -9 <PID>

Database connection error?
  docker-compose logs db
  docker-compose restart db

Tables not created?
  docker-compose exec app python -c "from database import init_db; init_db()"

View logs?
  docker-compose logs -f app
  docker-compose logs -f db

More help?
  See SETUP.md Troubleshooting section
