╔════════════════════════════════════════════════════════════════════════════╗
║                    HOW TO GET EACH API KEY                                ║
╚════════════════════════════════════════════════════════════════════════════╝

OpenAI:
  1. Go to https://platform.openai.com/account/api-keys
  2. Click "Create new secret key"
  3. Copy the key starting with "sk-"

Claude (Anthropic):
  1. Go to https://console.anthropic.com/
  2. Create API key
  3. Copy the key starting with "sk-ant-"

Groq:
  1. Go to https://console.groq.com
  2. Create API key
  3. Copy the key starting with "gsk-"

SendGrid:
  1. Go to https://app.sendgrid.com/settings/api_keys
  2. Create API key
  3. Copy the key starting with "SG."

Slack:
  1. Go to https://api.slack.com/apps
  2. Create new app
  3. Go to "Incoming Webhooks" and create webhook
  4. Copy the webhook URL

Sentry:
  1. Go to https://sentry.io/
  2. Create project
  3. Get DSN URL

PostgreSQL (AWS RDS):
  1. Create RDS instance
  2. Get endpoint, username, password
  3. Connection string: postgresql://user:pwd@endpoint:5432/dbname

Redis:
  1. Local: redis://localhost:6379/0
  2. Docker: docker run -d -p 6379:6379 redis:latest
  3. Cloud: https://redis.com or https://upstash.com
